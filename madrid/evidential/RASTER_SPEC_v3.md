0 DATA ENTRY (INPUTS OF THE MODEL)
- Ground data: one table with date, station code and the daily ground NO2 value (ug/m3) for the 24 Madrid stations over 236 dates (5,488 station-date cases); station coordinates (UTM x, y in metres). This is the only ground truth and the only data the interpolation uses.
- Satellite data: the station-level TROPOMI value (Earth Engine OFFL L3 tropospheric NO2 column in mol/m2, mean of the 1-2 same-day images at the station point), converted to ug/m3 by x 46.005e6/200. The exported 3x3 windows (5,664 rows) are used only for the satellite-only sensitivity S0 and the alignment diagnostics; the scene metadata documents the processor versions.
- Stored columns: the stored IDW value (reproducibility check only) and the stored fuse_var (unverified continuity value, see section 9; not the baseline B2). The kriging column is not used.
- TROPOMI product and assumptions: Earth Engine COPERNICUS/S5P/OFFL/L3_NO2 (HARP bin_spatial L3 product), band tropospheric_NO2_column_number_density, mol/m2, pixel 1113.2 m. The collection documentation states that the source pixels are filtered with a quality threshold of 75% for the NO2 tropospheric band; no additional QA filter is applied by us (section 6 of v2). Processor 2.8.0 until 2025-11-21 and 2.9.1 from 2025-11-22 (inherited from v2). The conversion to surface concentration assumes a 200 m mixing depth: the result is a column-derived concentration proxy, not a measured surface concentration; the linear calibration of section 5 absorbs a constant scale error but not its day-to-day variation.
- Fixed settings: class edges 15 and 30 ug/m3; floor eps = 0.05; no other input. Everything that is fitted (calibration, centroids, partition peaks, exemplars, widths, compatibility scale, dependence parameters) comes from training days 1-70 under the rule of section 1.

1 CASES AND SPLIT
- Cases: 24 stations x 236 dates = 5,664 possible station-dates, of which 5,488 are valid evaluation cases. The 176 missing = 46 station-dates without a TROPOMI value (19 completely empty windows and 27 windows with some cells but no old station-level value) + 130 station-dates that have a satellite value but no ground truth. Checked against the hourly ground files (NO2, magnitude 8; daily value = mean of the hours flagged valid, required at least 18 valid hours): 86 of the 130 have no hourly row and 44 have a row with fewer than 18 valid hours; none has 18 or more valid hours; all 5,488 stored truth values equal the recomputed daily means (maximum difference 0.0000). Cases per period: train days 1-70 = 1,645; validation days 71-140 = 1,657; final days 141-236 = 2,186 (not read before the pipeline is frozen).
- Each case: held-out station s, date t; the 23 other stations of that date are the only ground data used (leave-one-station-out).
- Strict fitting rule: for each held-out station h, EVERY fitted quantity (satellite calibration a, b, s_cal; class centroids; fuzzy-partition peaks; EK-NN exemplars and gamma; sigma(d) coefficients; compatibility scale s; dependence parameters) uses only training days 1-70 and only the 23 other stations; the IDW values of the training exemplars are computed without h and without the exemplar's own station. The held-out station's own data of any day is never used for fitting. The dependence parameters rho_ring and rho_AB (sections 6 and 8) obey the same rule: for each held-out station h they are estimated from training days and from station pairs and station-dates not involving h (pairs among the 23 other stations only). There is no pooled exception.

2 CLASSES
- Three classes: L < 15, M 15-30, H >= 30 ug/m3 (the old >=45 class has 6 validation cases and is merged into H). Centroids c_L, c_M, c_H = mean ground value per class on training days.

3 INTERPOLATED IMAGE
- IDW, power 2, from the 23 other stations (reproduces the stored idw column to within 0.02 ug/m3).
- Evaluated at 9 pixel positions around the held-out station: the station position itself and the 8 ring positions of a 3x3 window of the 1.1 km product grid (offsets about 1.11 km north-south and 0.85 km east-west in UTM metres). Only the set of positions matters, not their labelling.
- Kriging is not used (the original kriging code is lost).

4 MASSES FROM THE INTERPOLATED IMAGE: THREE VARIANTS (all parameters from training days only)
- V1 fuzzy partition: triangular (Ruspini) partition of the NO2 axis with peaks at c_L, c_M, c_H, shoulders outside; memberships mu_l(x). Probability p = mu; possibility pi = mu/max(mu), floored at eps = 0.05; BBA = consonant BBA of pi.
- V1 memberships are degrees of membership, NOT automatically calibrated probabilities. Using p = mu as input of the Rosenfeld relaxation is a convention. Calibration of the V1, V2 and V3 outputs is assessed (section 10) and not assumed; no recalibration is applied in the primary analysis.
- V2 evidential classifier (EK-NN, Denoeux 1995): for a pixel value x, take the k = 10 nearest training exemplars (interpolated value, true class); each gives mass alpha0*exp(-gamma*d^2) on its class and the rest on Theta, alpha0 = 0.95, gamma = 1/mean(d^2) over training pairs; combine by Dempster. Probability = BetP; possibility = normalised plausibility of singletons.
- V3 uncertainty-based width: Gaussian contour exp(-(x-c_l)^2 / (2 sigma(d)^2)) with sigma(d) = s0 + s1*d, d = distance of the pixel to the nearest included station, (s0, s1) fitted on training days, using the 23 other stations only, by minimising the Gaussian negative log-likelihood sum_i [ log sigma_i + e_i^2/(2 sigma_i^2) ] with sigma_i = s0 + s1*d_i, e_i = leave-one-out error of the IDW at training station-date i (station of i excluded from its own interpolation), d_i its distance to the nearest included station; bounds s0 >= 0.5 ug/m3, s1 >= 0; bounded numerical minimisation (L-BFGS-B, start s0 = RMSE, s1 = 0); contour floored at eps = 0.05. Probability = Gaussian class-interval masses with sigma(d); BBA = consonant BBA of the contour. A pixel far from stations has a wider contour and more ignorance.
- The three variants are compared; none is declared best in advance.

5 SATELLITE EVIDENCE (the same for all variants, so variants differ only on the interpolation side)
- Calibrated satellite value x_sat = a + b*c_old (old station-level TROPOMI value) -> consonant BBA of a Gaussian contour with sigma = s_cal, floor eps = 0.05. Strict rule: (a, b, s_cal) are re-estimated for EACH held-out station h from training days 1-70 and the 23 other stations (24 fits). Checked numerically: the pooled fit that used all 24 stations (a = 11.11, b = 0.484, s_cal = 10.76, used in the v2 satellite-only validation run S0 and in the rho_sp diagnostic) violated this rule; the strict fits range over a 10.70-11.79, b 0.479-0.496, s_cal 10.47-10.87, so the effect is small. S0 will be recomputed under the strict rule; the pooled numbers are not used in v3.

6 RELAXATION (centre pixel of the interpolated image, using its 8 ring pixels)
- Probabilistic (Rosenfeld). Classes l = 1..3, centre probabilities p(l) (V1: p = mu; V2: BetP; V3: Gaussian class-interval masses), neighbour probabilities p_j(l), j = 1..8, fixed. Compatibility r(l,l') = [1, 0.5, -0.5][|l-l'|] (medium matrix restricted to K = 3). Iterate t = 1..3: q(l) = mean_j sum_l' r(l,l') p_j(l'); p(l) <- p(l)(1+q(l)) / Z, Z = sum_l p(l)(1+q(l)). Since |q| <= 1 the factors are non-negative.
- Possibilistic (frozen v1 update). Centre contour pi0, neighbour contours pi_j. For each neighbour and class k: s_j(k) = max_l min(pi_j(l), R(k,l)) (sup-min composition with the physical compatibility R). A(k) = the m-th largest of s_1(k)..s_8(k), m = 3. kappa = 1 - max_k A(k); Abar(k) = max(A(k), kappa) / max_k' max(A(k'), kappa). Damped update, T = 3 times: pi <- (1-gamma) pi + gamma min(pi, Abar); pi <- pi / max pi; gamma in {0.25, 0.5, 0.75}. No new tuning.
- Canonical weights (used by the cautious rule and by CDD). For a BBA m with m(Theta) > 0 on the K = 3 frame, the commonality is q(A) = sum_{B superset of A} m(B), including A = empty (q(empty) = total mass = 1). The weights w(A) are defined for every A proper subset of Theta, empty set included, by the canonical decomposition q(C) = prod_{A: C not subset of A} w(A), solved by the standard recursion over sets by decreasing size (log q additive); the inverse transform rebuilds q from the weights by the same product and m by Moebius inversion. Validity: the decomposition requires m(Theta) > 0 (all weights finite and positive); BBAs here have m(Theta) >= eps-related positive mass or are discounted. A combined weight set is accepted only if the rebuilt masses are all >= -1e-9; negative masses beyond this tolerance are counted and reported (the invalid-count per method), the case then falls back to the conjunctive rule and is flagged. Weights are not assumed separable: the cautious rule takes min of weights, the CDD raises weights to a power; both are standard for the canonical decomposition and are not claimed to preserve any property beyond the checks C5, C6 and C12. Test already run (K = 3, training days only, 1,200 BBAs per stage: consonant, projected, cautious pool, cautious centre): 0 negative masses, weight-to-mass round trip error 0.
- Evidential: (i) projection of a neighbour BBA m_j with reliability rho: the empty-set mass m_j(empty) is carried over unchanged; for every focal set F that is neither empty nor Theta, the contour pi_F(l) = max over k in F of R(k,l) (upper envelope of the rows of R; R(k,k) = 1 so the maximum is 1) is converted to its consonant BBA Con(pi_F) (levels sorted, tied levels merged, zero-weight sets dropped), weighted by rho*m_j(F); the remaining mass 1 - m_j(empty) - sum_F rho*m_j(F) goes to Theta (it contains m_j(Theta) and the share (1-rho) of every projected set). The result sums to 1 including the empty set; for a singleton F it equals rho*Con(R_k) + (1-rho)*Theta. (ii) Primary: cautious pool of the 8 projected BBAs (canonical weights include the empty-set weight, rho in {0.5, 0.8, 0.95}), then cautious combination with the centre BBA. Comparators: cautious pool + Dempster centre; Dempster all. (iii) CDD (neighbour pool): sources = the centre BBA and the 8 projected neighbour BBAs, k = 9; the canonical weights w_i(A) of every source (A a proper subset of Theta, including the empty set) are raised to the same exponent lambda = 1/(1+(k-1)*rho_ring), centre included, multiplied across sources (conjunctive rule on weights) and the BBA is recovered by the inverse transform, m(empty) retained; rho_ring = mean pairwise correlation of the IDW leave-one-out residuals of station pairs among the 23 stations other than h (each with its eight nearest, training days, out-of-fold, Fisher-averaged, clipped to [0,1]), so it is a separate value for each held-out station; at rho_ring = 0, lambda = 1 and CDD equals the conjunctive rule. The satellite value rho_sp = 0.782 is NOT used for interpolation pixels.
- R(k,l) = exp(-(c_k-c_l)^2/(2 s^2)) with s = training RMSE of the interpolation.
- Sensitivity S1: neighbours = the nearest 4 stations with their observed classes (as in the earlier station study) instead of ring pixels.

7 DEFUZZIFICATION
- BetP is always computed on the normalised non-empty masses m(A)/(1-m(empty)) (when m(empty) = 1 the case is flagged and BetP is uniform). Value = sum over classes of BetP(l)*c_l (soft). Sensitivities: hard (centroid of the top class); correction mode x_idw + (soft relaxed - soft unrelaxed), which keeps the continuous detail and isolates the relaxation effect.

8 COMBINATION WITH THE SATELLITE
- Interpolation BBA after relaxation (m_A). m_rel = the relaxed classification written as a BBA (evidential: the relaxed BBA itself, empty-set mass included; possibilistic: the consonant BBA of the relaxed contour; probabilistic: the Bayesian BBA of the relaxed probabilities mixed with the vacuous BBA at weight eps = 0.05). x_r = defuzzified value of m_rel (section 7), computed from BetP of the normalised non-empty masses.
- Construction (primary): ONE common contour form for all three variants: pi(l) = exp(-(x_r - c_l)^2 / (2 sigma_A^2)), normalised to maximum 1, floored at eps = 0.05, converted to its consonant BBA Con_sigma (a BBA without empty-set mass). Conflict-preserving reconstruction: m_A(empty) = m_rel(empty); the non-empty part of m_A is (1 - m_rel(empty)) * Con_sigma, with sigma_A chosen so that Con_sigma(Theta) = m_rel(Theta)/(1 - m_rel(empty)); hence m_A(Theta) = m_rel(Theta) and m_A sums to 1. Possibilistic and probabilistic m_rel have no empty-set mass, so for them m_A = Con_sigma. Thus the conflict created by the evidential relaxation is carried into the combination with the satellite and is not discarded. The variants differ only through x_r, m_rel(Theta) and m_rel(empty), not through the contour form. sigma_A solves m_A(Theta) = m_rel(Theta), where m_A(Theta) is the lowest contour level and increases monotonically with sigma_A: bisection on sigma_A in [0.5, 200] ug/m3, tolerance 1e-4 on m_A(Theta), at most 60 iterations.
- Root-search failures: if m_rel(Theta) < eps the target is set to eps; if m_rel(Theta) exceeds the value reached at sigma_A = 200, sigma_A = 200 is used; if the search does not converge the closest reachable sigma_A is used. The number and share of such cases are reported per variant and relaxation type; no case is dropped.
- Information lost relative to the sensitivity S3 (m_A = m_rel directly): the reconstruction keeps three numbers, the centre x_r, the ignorance level m_rel(Theta) and the conflict m_rel(empty). It discards how the mass is distributed among classes and composite sets (for example mass shared by L and H, or bimodal relaxed evidence), the exact focal sets and any non-consonant structure; S3 keeps all of it. S3 is a sensitivity analysis; the primary follows the five stages of the author's method.
- Satellite BBA m_B as in section 5.
- Primary rule: unnormalised conjunctive (TBM) combination of m_A and m_B, with m(empty) retained and reported as the final conflict. The pignistic probability and the final value are computed on the normalised masses m/(1-m(empty)), which gives the Dempster result for decisions; Dempster-normalised masses are never used to report conflict. Rationale (working assumption, not a proved property): the interpolation comes from ground stations and the satellite value from another sensor with its own retrieval error, and the held-out station enters neither the calibration nor the interpolation (strict rule), so m_A and m_B are treated as if they came from distinct sources; formal distinctness is not claimed. The conjunctive rule then reinforces agreement and exposes disagreement as conflict. Dependence between the two errors (shared weather, the calibration trained on the same ground stations) cannot be excluded, hence the dependence sensitivities below and the measured rho_AB.
- Sensitivities (dependence): cautious rule (unknown dependence); CDD with k = 2 sources m_A and m_B, canonical weights (proper subsets including the empty set) of both raised to the same exponent lambda = 1/(1+rho_AB), multiplied, inverse transform; rho_AB = correlation between the IDW leave-one-out residual and the calibrated-satellite residual at the same station-date, over the 23 stations other than h (training days, out-of-fold, clipped to [0,1]; a separate value for each held-out station); rho_AB = 0 gives the conjunctive rule.
- Conflict and ignorance are reported as separate quantities: m(empty) (disagreement) and m(Theta) (lack of information); neither defines the other or an abstention rule.
- Final value = defuzzification (section 7) of the combined normalised BBA.

9 BASELINES (same cases)
- B0 IDW alone; B1 calibrated satellite alone; B2 plain inverse-variance fusion of IDW and calibrated satellite, recomputed under the strict rules (B2-strict: weights from the training-day error variances of IDW and of the calibrated satellite, 23 stations, for each held-out station h). The stored fuse_var column (RMSE 6.56 on all cases) could not be reproduced from the stored columns (best linear combination of idw and sat_reg: RMSE 3.1 from it) and its original code is lost; it is reported only as an unverified continuity value 'B2-stored' and is not used for any conclusion; B3 the same evidential combination WITHOUT relaxation (isolates what relaxation adds); relaxation types as in section 6.

10 METRICS AND SELECTION
- RMSE, MAE, bias, class accuracy and multiclass Brier of the final BBA, conflict m(empty).
- Paired 7-day block bootstrap (all stations of a date together) of the RMSE difference: relaxed vs B3, relaxed vs B2, variants against each other. Report cases, dates, stations, blocks. Bootstrap details: blocks are non-overlapping groups of 7 consecutive panel days; the validation period (70 days) gives exactly 10 blocks; the final period (96 days) gives 13 blocks of 7 and one block of 5; resampling of blocks with replacement, B = 2000, seed 1, percentile interval 2.5/97.5; every station of a selected date goes with it.
- Selection on validation only: variant, rho_proj, gamma by validation RMSE of the final combined value; all grid points reported (multiplicity). Final period run once after freezing.
- Calibration assessment (not assumed): reliability table (10 bins), ECE and Brier of the pignistic probabilities of each variant, and of the membership-derived probabilities of V1; reported, no recalibration in the primary analysis.

11 LIMITS
- IDW is smooth, so the ring pixels may carry little independent information; reported as a result, not rescued.
- Centroid defuzzification compresses extremes (the soft estimate cannot exceed the class centroids).
- Processor change on 2025-11-22 falls entirely in the final period; alignment cause unconfirmed; ground stations are not independent replications.

12 EXPECTED OUTPUTS
- Per validation case: the final NO2 estimate (ug/m3) at the held-out station; the relaxed-defuzzified interpolation value; for the combined evidence m(Theta), m(empty) and the pignistic probabilities of L, M, H; the predicted class.
- Tables: RMSE, MAE and bias for every method and mass variant (V1, V2, V3) against the baselines B0-B3; paired block-bootstrap differences with 95% intervals (relaxed vs B3 = effect of relaxation; relaxed vs B2 = effect against the plain fusion; variants against each other); class accuracy and Brier; conflict distribution m(empty); sensitivity tables S0-S3; diagnostics (centroids, calibration, s_cal, sigma(d) coefficients, rho_ring, rho_AB).
- Files: summary table, per-case predictions, bootstrap table and a configuration file with every fitted parameter, so that the run can be reproduced.
- Scope of the output: the pipeline defines a value for every pixel, but ground truth exists only at the 24 stations, so evaluation is at the held-out station positions. A full NO2 map is a possible illustration for the paper and is not part of the scoring.
- No improvement is assumed in advance. A null or negative result is reported as it comes out, and the final period is run once after freezing.

13 IMPLEMENTATION CHECKS (before the first validation run)
- C1 counts: 24 x 236 = 5,664; 5,488 cases; 46 + 130 = 176; split 1,645 / 1,657 / 2,186.
- C2 strict LOSO: for a held-out station h, changing every row of h in the fitting data must not change any fitted parameter (a, b, s_cal, centroids, peaks, exemplars, gamma, sigma(d), s); IDW of exemplars computed without h and without the exemplar's own station.
- C3 IDW with 23 stations reproduces the stored idw column within 0.03 ug/m3.
- C4 projection: sums to 1 including the empty set for random BBAs with composite focal sets and empty-set mass; the singleton case equals rho*Con(R_k) + (1-rho)*Theta; upper-envelope contour has maximum 1.
- C5 cautious audit including the empty-set weight (idempotent, commutative, associative to about 1e-15; audit.py).
- C6 CDD: lambda = 1 equals the conjunctive rule; identical copies of a source are not over-counted when rho = 1.
- C7 root search: m_A(Theta) equals the target within 1e-4; report failures and clipping per variant and relaxation type.
- C8 conflict and ignorance reported separately; pignistic computed on normalised masses; Dempster-normalised masses never used for conflict.
- C9 relaxation switched off reproduces baseline B3 exactly.
- C10 leakage: the validation script loads no row of days 141-236 and asserts the maximum day used is 140.
- C11 calibration/reliability tables produced for V1, V2, V3.
- C12 canonical decomposition on the actual V1/V2/V3 BBAs, projected BBAs, pools and CDD outputs: count of rebuilt masses < -1e-9 per stage (expected 0; any count is reported and handled as in section 6); weight-to-mass round trip.
- C13 conflict preservation: for evidential relaxation m_A(empty) = m_rel(empty) and m_A(Theta) = m_rel(Theta) after reconstruction; for the other two m_A(empty) = 0.
- C14 BetP always from normalised masses; flagged cases with m(empty) = 1 counted.
- C15 per-held-out-station parameters: rho_ring and rho_AB recomputed with station h removed; changing all rows of h leaves them unchanged (extension of C2); B2-strict uses the same rule.
- C16 data provenance: truth equals the daily mean of valid hourly values (>= 18 valid hours) for all 5,488 cases; the 130 satellite-only station-dates are classified as no hourly row (86) or fewer than 18 valid hours (44).
